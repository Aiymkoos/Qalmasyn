# Qalmasyn

Интерактивный дизайн-прототип сервиса вечерних предложений в Казахстане. Qalmasyn — бренд платформы; Karak House показан только как пример возможного партнёра.

## Просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Для локального сервера:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4173/index.html

## Подключение настоящей базы данных (Supabase)

Интеграция включается, если в `config.js` заполнены оба поля: `supabaseUrl` и `supabaseAnonKey`. Если хотя бы одно поле пустое, запросы к Supabase не отправляются.

1. Создайте новый проект на [Supabase](https://supabase.com/dashboard).
2. Откройте **SQL Editor** → **New query**, вставьте весь файл `supabase.sql` и нажмите **Run**. Он создаст таблицы, безопасную операцию бронирования и семь демонстрационных предложений.
3. В **Project Settings** → **API** скопируйте `Project URL` и публичный `anon` key.
4. Вставьте их в `config.js` в поля `supabaseUrl` и `supabaseAnonKey`.

При успешных запросах новые предложения, количество порций и брони сохраняются в базе. Вместе с бронью отправляются имя и телефон гостя, код, цена и ID предложения; вместе с предложением — заполненные поля кабинета и загруженное фото. В сайт нельзя добавлять `service_role` key: это секретный ключ только для сервера.

## Приложение на iPhone (PWA)

Проект уже содержит `manifest.webmanifest`, сервис-воркер и иконки. После публикации по HTTPS откройте сайт в Safari → **Поделиться** → **На экран «Домой»**. Qalmasyn будет открываться как отдельное приложение и сможет показать сохранённую версию интерфейса без сети.

Сервис-воркер сначала запрашивает актуальные файлы интерфейса и использует кеш только без сети. Ответы Supabase и 2GIS не кешируются; офлайн-каталог содержит демонстрационные предложения и не подтверждает актуальные цены или остатки. Для бронирования с подключённой базой нужна сеть. При обновлении сервис-воркер удаляет старые кеши Qalmasyn.

## Что работает

- Поиск, категории, районы Караганды, фильтры цены и скидки, сортировка.
- Избранное, карточка предложения, состав и аллергены, время самовывоза.
- Тестовая бронь с кодом; количество уменьшается, при отмене восстанавливается.
- Кабинет заведения: добавление предложения, проверка цены, загрузка фото.
- Адаптивная компоновка с нижней навигацией на телефоне, управление с клавиатуры и нативные диалоговые окна.

## Границы прототипа

Заведения и предложения в исходном наборе — демонстрационные. Онлайн-оплата не подключена. Реальное обслуживание заведениями не подтверждено.

В `localStorage` этого браузера сохраняются брони, включая имя и телефон гостя, ID избранных предложений, настройки слежения за ценой и выбранный язык. Обновление страницы эти данные не удаляет. Кабинет показывает брони из того же браузера; отдельной загрузки списка броней с сервера нет.

При включённом Supabase имя и телефон гостя и остальные данные брони отправляются на сервер. Бронь подтверждается и сохраняется локально после успешного ответа сервера; при ошибке показывается сообщение, а бронь не создаётся локально. При выключенном Supabase бронь сохраняется только в браузере.

Добавленное предложение отправляется в Supabase, если интеграция включена, и сохраняется в базе после успешного запроса. Без Supabase или при ошибке отправки оно остаётся только в памяти страницы до обновления. Для демонстрации можно использовать вымышленные данные.

Роль заведения не имеет авторизации; правила `supabase.sql` разрешают публичное чтение и добавление предложений. Для реального запуска нужны отдельные аккаунты, разграничение доступа и подтверждённый процесс оплаты/самовывоза.

Тексты — на русском и казахском; демонстрационный город — Караганда. Фотографии и иконки находятся локально в `assets/`. Rubik, Onest и Aclonica загружаются из Google Fonts; без сети используются системные шрифты.

## Проверка

Автоматические регрессии требуют Node.js 20+:

```sh
npm ci
npx playwright install chromium
npm test
```

Для установленного браузера можно задать `PLAYWRIGHT_EXECUTABLE_PATH` вместо загрузки Chromium. Мобильные тесты загружают настоящие шрифты Google Fonts, поэтому им нужен доступ к `fonts.googleapis.com` и `fonts.gstatic.com`.

Проверяются экраны 320/390/430 px на русском и казахском, доступность кнопок, избранное и фильтры, создание и отмена брони с обновлением страницы и защитой повторной отправки. Supabase подменён тестовой базой: рабочие записи не создаются. PWA проверяется отдельным настоящим сервис-воркером, включая установку, очистку старого кеша, точные URL и офлайн-загрузку. Это эмуляция браузера, без физического iPhone или Android.

В браузере проверены поиск и пустое состояние, категории, цена и район, добавление/удаление избранного, сохранение фокуса, ошибочный телефон, создание/отмена брони, восстановление количества, ошибочная цена и публикация предложения партнёром. Проверены размеры 320, 390, 768 и 1440 px. Также выполнены `node --check app.js` и `git diff --check`.

## Умная цена и аналитика

- Цена предложения плавно снижается от стартовой (начало окна выдачи) до минимальной (конец окна). Закреплённая панель «Демо: перемотка вечера» двигает время (и цвет страницы), чтобы показать это в демо.
- Цена брони фиксируется в момент бронирования.
- Заведение включает умную цену и задаёт минимальную цену в кабинете.
- Кабинет показывает демо-аналитику по часам и прогноз на завтра; на главной есть счётчик спасённых порций и CO₂ (оценка).
