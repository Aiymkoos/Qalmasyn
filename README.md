# Qalmasyn

Интерактивный дизайн-прототип сервиса вечерних предложений в Казахстане. Qalmasyn — бренд платформы; Karak House показан только как пример возможного партнёра.

## Просмотр

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Для локального сервера:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:4173/index.html

## Что работает

- Поиск, категории, районы Караганды, фильтры цены и скидки, сортировка.
- Избранное, карточка предложения, состав и аллергены, время самовывоза.
- Тестовая бронь с кодом; количество уменьшается, при отмене восстанавливается.
- Кабинет заведения: добавление предложения, проверка цены, загрузка фото.
- Адаптивная компоновка с нижней навигацией на телефоне, управление с клавиатуры и нативные диалоговые окна.

## Границы прототипа

Заведения, наличие, расстояния, фотографии и цены — демонстрационные. Платежи и заказы не отправляются. Данные бронирований и добавленные предложения живут в памяти страницы до обновления; в localStorage сохраняются только ID избранных карточек. Поля кабинета и гостей не передаются на сервер. Роль заведения в этом макете не имеет авторизации — для реального запуска нужны отдельные аккаунты, серверное хранение, проверка остатков и интеграция оплаты/самовывоза.

Тексты — на русском; первым демонстрационным городом сохранена Караганда из исходного макета. Фотографии и иконки находятся локально в `assets/`. Manrope и Lora загружаются из Google Fonts; без сети используются системные шрифты.

## Источники решений

- [OpenAI: Using GPT-6](https://developers.openai.com/api/docs/guides/latest-model) — рекомендации по работе с GPT-6 Astra и проверке результата.
- [OpenAI: Frontend prompt instructions](https://developers.openai.com/api/docs/guides/frontend-prompt) — иерархия, реальные изображения, рабочие сценарии, адаптивность. Этот отдельный frontend-гайд помечен как ориентированный на GPT-5.5, с применимостью принципов к другим моделям; это не отдельный фирменный дизайн-стандарт Astra.
- Через Context7 MCP (`query-docs`, 30.09.2026) проверены [MDN: dialog](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog), `showModal()`, блокировка фона, закрытие по Escape и начальный фокус; использован источник `/mdn/content`.
- Через Context7 MCP проверена интеграция [Lucide для JavaScript](https://lucide.dev/guide/lucide) (`/websites/lucide_dev`). Локальная библиотека Lucide 0.547.0, лицензия в `assets/lucide-LICENSE.txt`. Декоративные иконки скрыты от скринридера; кнопки имеют текстовые названия.

## Проверка

В браузере проверены поиск и пустое состояние, категории, цена и район, добавление/удаление избранного, сохранение фокуса, ошибочный телефон, создание/отмена брони, восстановление количества, ошибочная цена и публикация предложения партнёром. Проверены размеры 320, 390, 768 и 1440 px. Также выполнены `node --check app.js` и `git diff --check`.

## Умная цена и аналитика

- Цена предложения плавно снижается от стартовой (начало окна выдачи) до минимальной (конец окна). Закреплённая панель «Демо: перемотка вечера» двигает время (и цвет страницы), чтобы показать это в демо.
- Цена брони фиксируется в момент бронирования.
- Заведение включает умную цену и задаёт минимальную цену в кабинете.
- Кабинет показывает демо-аналитику по часам и прогноз на завтра; на главной есть счётчик спасённых порций и CO₂ (оценка).
